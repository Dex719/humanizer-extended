# Full vs slim, 2026-10-11

**Result:** on 16 texts (8 English, 8 Russian), a blind judge preferred `humanizer-slim` 10 times, the full skill 3 times, and called 3 ties. Slim left about half as many AI tells (12 vs 22) and invented or lost no more than the full skill. Treat this as a direction, not a verdict: each skill ran once per text, one model judged, and two of the 16 texts were used while tuning slim.

## Setup

| | |
|---|---|
| Skills | `SKILL.md` (full) and `skills/humanizer-slim/SKILL.md`, both at 2.22.0 |
| Rewriting model | Claude Sonnet 5.5, one run per skill per text, no writing sample |
| Inputs | 6 new English texts generated by Claude Haiku 5.5 from fact lists (prompts in `../../corpus/en_*.json`), plus the 10 `before` texts already in `eval/corpus/` |
| Automatic scoring | `score.py`: immutable-token audit, `contrast_frames`, structural and compliance checks from `eval/metrics.py` |
| Blind review | Claude Opus 5.5 saw the input and two anonymous rewrites A/B in random order (`judge_items.json`); the mapping is in `judge_key.json` |

## Blind review

| | Wins | Added claims | Lost claims | Remaining tells | Naturalness (1–5) |
|---|---:|---:|---:|---:|---:|
| Full | 3 | 1 | 4 | 22 | 3.94 |
| Slim | 10 | 1 | 3 | 12 | 4.12 |

Findings both skills shared, all fixed after this run:

- Both dropped "the goal wasn't speed" from the weekly-releases post. Readers would expect weekly releases to mean speed, so the contrast was legitimate. Pattern 9 now keeps such a contrast in one plain clause ("for predictability, not speed").
- Both added a causal "so" (`поэтому`) between two facts in `ru-science-sleep`. Both skills now forbid adding causal links the input does not state.
- Slim kept the ad formula `для тех, кто ценит…`; it is now on the sales-language list.

`out_slim_v2.json` holds slim's rerun on the four affected texts after those fixes; the weekly-releases outputs there are the README before/after images.

## What this run also fixed in the metrics

The first scoring pass reported 17–21 Russian violations that were not real: modal synonyms (`следует` → `стоит`), deleted rhetorical frames (`нельзя не заметить`), and case endings on names (`Корнеева` → `Корнееву`). The audit now compares modality by class, ignores negations and modals inside staged contrasts and rhetorical frames, and matches Russian names across cases.

## Limits

- One run per skill per text; model output varies between runs.
- One judge model, which may share blind spots with the rewriting model.
- English inputs from a 2026 model are fairly clean: no dashes, no not-X-but-Y. They test restraint more than cleanup.
- `en-blog-weekly-releases` and `ru-blog-weekly-releases` were used while writing slim.
